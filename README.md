# F10 - MHAD-CLRS

Code for Multi-Head Attention and Dual Message-Passing Neural Network for Neural Algorithmic Reasoning paper, to be presented in ENIAC 2026 can be found in the following repositories:

- https://github.com/falreis/clrs/tree/f10-algorithm
- https://github.com/IMScience-PPGINF-PucMinas/mhad-clrs

The [branch in the current repository](https://github.com/falreis/clrs/tree/f10-algorithm) contains the original code with all experiments and logs. The name of our method in this branch is F10, an internal name.

The [repository in IMScience lab](https://github.com/IMScience-PPGINF-PucMinas/mhad-clrs) is the official code version. It contains the code anonymized and reorganized to follow ENIAC's submission protocol.

## Getting started

The MHAD-CLRS can be installed using [virtual environment](https://docs.python.org/pt-br/3/library/venv.html) using [requirements.txt](requeriments/requeriments.txt) file.

MHAD-CLRS also can be running using the [Google Colab file](clrs.ipynb).
